# 教学计算

[welfare_examples.py](welfare_examples.py) 使用 Python 3 标准库，不需额外安装包。在仓库根目录运行：

```sh
python code/welfare_examples.py
```

Windows 已安装 Python Launcher 时也可用 `py code/welfare_examples.py`。

| 例子 | 应看到的关键结果 |
|---|---|
| 商品税为 10 | 数量 80，税收 800，无谓损失 100 |
| 税额从 10 到 11 | 福利精确变化为 -21 |
| 最高税率 | 0.6400 |
| 仅弹性有抽样误差 | 标准误 0.0384，近似区间 0.5647—0.7153 |
| 消费边际效用差距 | 0.5625；一阶近似 0.4000 |
| MVPF | 2.5000 |
| 本国份额从 0.8 到 0.7 | 福利提高约 3.39% |

这些都是笔记中公式的教学代入。脚本没有估计弹性、验证模型假设或识别真实政策效果；只固定一部分输入的标准误示例，也不代表完整政策不确定性。
